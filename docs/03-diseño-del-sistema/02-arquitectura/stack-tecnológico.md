# Stack Tecnológico

| Capa | Tecnología | Rol |
| :--- | :--- | :--- |
| Frontend | React + Vite | SPA (Single Page Application) de alta velocidad. |
| Estilos | Tailwind CSS | Diseño responsivo basado en utilidades. |
| Backend | Python (FastAPI o Flask) | API REST para procesamiento de archivos. |
| Lógica Doc | python-docx | Generación y manipulación de archivos Word. |
| Comunicación | HTTPS / JSON | Protocolo de intercambio de datos. |
| Despliegue | Docker | Contenerización (Dockerfile + Docker Compose). |
