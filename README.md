# Proyecto para transformar estructuras JSON en exámenes profesionales formato .docx.

## Stack
- **Backend:** Python + FastAPI + python-docx
- **Frontend:** React + Tailwind CSS
- **Arquitectura:** Clean Architecture
- **Despliegue:** Docker

## Flujo de Usuario
1. **Carga:** El usuario selecciona un archivo JSON.
2. **Configuración:** Opción de incluir datos (Nombre, Curso, Fecha).
3. **Previsualización:** Vista previa de los datos antes de generar.
4. **Descarga:** Generación independiente de Cuestionario y Hoja de Respuestas.
